PROJECT SUMMARY
───────────────────────────────────────────────────────────────────────────

api_label is a comprehensive product label generation system designed to
create regulatory-compliant labels in multiple languages (ES/EN) with PDF
export, barcode integration, and background task processing.

Key Technologies:
- FastAPI (async web framework)
- PostgreSQL + SQLAlchemy (async ORM)
- Redis (cache & Celery broker)
- ReportLab (PDF generation)
- Babel (internationalization)
- Celery (task queue)
- slowapi (rate limiting)
