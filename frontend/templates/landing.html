Como funciona

Tres pasos para generar tu etiqueta conforme a normativa

1

Escanea o introduce

Escanea el codigo de barras del producto o introduce los datos manualmente. Nuestro sistema obtiene la informacion del producto al instante.

2

Configura tu etiqueta

Selecciona la categoria (nutricional, cosmetica, electronica...), idioma, formato y personaliza los campos que necesites.

3

Descarga y usa

Genera tu etiqueta en PDF de alta calidad o HTML embebible. Lista para imprimir o integrar en tu web o sistema.

Todo lo que necesitas para tus etiquetas

Herramientas profesionales para cumplir con la normativa sin complicaciones

Etiquetas nutricionales

Tablas nutricionales completas con valor energetico, macronutrientes, vitaminas y minerales segun el formato legal europeo.

Cumplimiento normativo

Etiquetas conformes al Reglamento (UE) n. 1169/2011 y otras regulaciones sectoriales europeas y nacionales.

Escaner EAN/UPC

Escanea codigos de barras EAN-13, UPC-A y otros formatos con la camara del movil o introduce el codigo manualmente.

PDF y HTML

Descarga etiquetas en PDF de alta resolucion listas para imprimir, o en HTML responsivo para integrar en tu web.

API REST con tokens

Integra la generacion de etiquetas en tu sistema mediante nuestra API REST. Tokens personales para acceso programatico seguro.

Multiidioma

Genera etiquetas en espanol, ingles y mas idiomas. Perfecto para productos destinados a mercados internacionales.

Cumplimiento normativo

Etiquetas que cumplen la ley

Nuestro motor de generacion sigue las directrices del Reglamento (UE) n. 1169/2011 sobre informacion alimentaria facilitada al consumidor. Ademas, cubrimos normativa especifica para:

  • Alimentacion — Tablas nutricionales, alergenos, ingredientes, fecha de caducidad
  • Cosmetica — Ingredientes INCI, advertencias, PAO, lote
  • Electronica — Marcado CE, RAEE, informacion del fabricante
  • Ferreteria — Fichas de seguridad, pictogramas, indicaciones de peligro
